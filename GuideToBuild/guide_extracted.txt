SmartMove Transport Solutions
Cross-Platform Setup & Deployment Guide (New PC / Environment)
1. Executive Summary & System Requirements
This document provides a step-by-step technical guide to setting up and running the SmartMove Transport Solutions hybrid application (PHP 8.2 + Oracle Database + MongoDB NoSQL) on a fresh Windows computer.

2. Step-by-Step Setup Instructions
Step 1: Install & Configure XAMPP (PHP 8.2)
1. Download and install XAMPP for Windows (with PHP 8.2.x) to default path: C:\xampp.2. Open C:\xampp\php\php.ini in a text editor (e.g., Notepad++ or VS Code).3. Search for extension directives and ensure the following lines are enabled (remove leading semicolons):
extension=oci8_19    ; Enables Oracle Database extensionextension=mongodb    ; Enables MongoDB NoSQL extension
[EXTENSION CHECK] If extension=mongodb is missing from php.ini, download php_mongodb.dll (PHP 8.2 Thread Safe x64), place it in C:\xampp\php\ext\, and add 'extension=mongodb' to php.ini.
Step 2: Install & Configure Oracle Database XE
1. Install Oracle Database Express Edition (19c or 21c XE).2. Note your SYS/SYSTEM administrative password set during installation.3. Install Oracle Instant Client (64-bit) and append its path (e.g., C:\oracle\instantclient_19_19) to your System PATH Environment Variable.4. Open SQL*Plus or SQL Developer and create the project schema user:
-- Connect as SYSDBACONNECT sys/YourPassword@localhost:1521/XEPDB1 AS SYSDBA;-- Create SmartMove Database UserCREATE USER smartmove_user IDENTIFIED BY password123;GRANT CONNECT, RESOURCE, CREATE VIEW, CREATE PROCEDURE, CREATE TRIGGER TO smartmove_user;ALTER USER smartmove_user QUOTA UNLIMITED ON USERS;
Step 3: Install & Configure MongoDB
1. Download & Install MongoDB Community Server and MongoDB Compass GUI.2. Ensure MongoDB Windows Service is running on port 27017.3. Test connectivity in MongoDB Compass using connection URI: mongodb://localhost:27017
Step 4: Deploy Project Codebase to XAMPP
1. Copy the entire project folder to: C:\xampp\htdocs\SmartMoveTransport.2. Open PowerShell or Command Prompt, navigate to the project directory, and install dependencies via Composer:
cd C:\xampp\htdocs\SmartMoveTransportcomposer install
Step 5: Execute Database Initialization Scripts
1. Execute the Oracle DDL & PL/SQL scripts to create tables, triggers, sequences, and procedures:
sqlplus smartmove_user/password123@localhost:1521/XEPDB1 @database/oracle_schema.sqlsqlplus smartmove_user/password123@localhost:1521/XEPDB1 @database/oracle_plsql_reports.sql
2. Seed initial MongoDB documents (reviews, vehicle docs, notifications) using Mongo Shell or Compass:
mongosh mongodb://localhost:27017/smartmove_db database/mongo_seed.js
3. Verification & Troubleshooting
1. Start Apache from the XAMPP Control Panel.2. Open your web browser and navigate to: http://localhost/SmartMoveTransport/
Issue / Error Message
Root Cause & Resolution
Call to undefined function oci_connect()
oci8 extension is disabled or Oracle Instant Client is missing from PATH. Enable 'extension=oci8_19' in php.ini and restart Apache.
Class 'MongoDB\Client' not found
Composer dependencies have not been installed. Run 'composer install' inside C:\xampp\htdocs\SmartMoveTransport.
ORA-12154: TNS:could not resolve service name
Check database TNS string in config/db.php. Ensure Oracle service name matches XEPDB1 or XE.
